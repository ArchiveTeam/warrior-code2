warrior-code2
=============

Boot scripts for the ArchiveTeam Warrior 2 (legacy).

* For general overview, see the [Archive Team Warrior wiki page](http://archiveteam.org/index.php?title=Warrior) for more information.
* To run under a virtual machine (operating system virtual machine images), see [warrior4-vm](https://github.com/ArchiveTeam/warrior4-vm) instead. 
* To run under a Docker container (Dockerfile images), see [warrior-dockerfile](https://github.com/ArchiveTeam/warrior-dockerfile).
* For the project management code, see [seesaw-kit](https://github.com/ArchiveTeam/seesaw-kit/).

Do not run scripts directly in this repository. These scripts are used by the Docker image as a legacy boot process. Other uses are obsolete (such as [warrior-preseed](https://github.com/ArchiveTeam/warrior-preseed)).
